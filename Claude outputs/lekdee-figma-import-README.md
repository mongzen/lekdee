# นำดีไซน์ "เลขดี" เข้า Figma

ไฟล์ Figma ที่สร้างไว้ให้แล้ว (เปล่า พร้อมวาง):
**https://www.figma.com/design/L2Lk5Z35AooZRviwmSqgVp**

## วิธีนำเข้า (30 วินาที ต่อ 1 หน้า)

1. เปิดไฟล์ Figma ด้านบน
2. ลากไฟล์ `.svg` ทั้ง 4 ไฟล์ (ทีละไฟล์ หรือพร้อมกัน) จากเครื่องคุณ วางลงบน canvas ของ Figma โดยตรง
3. แต่ละไฟล์จะกลายเป็นเฟรมที่แก้ไขได้จริง — ทุกกล่อง ทุกตัวอักษร ทุกสี แยกเป็นเลเยอร์ ปรับแก้ต่อได้ทันที ไม่ใช่แค่รูปภาพ
4. แนะนำให้ตั้งชื่อเฟรม/เพจใน Figma ตามนี้เพื่อให้เป็นระเบียบ:
   - `01 Overview` (ภาพรวม)
   - `02 Ritual` (ขอเลขสิ่งศักดิ์สิทธิ์)
   - `03 Chat` (เจ้าแม่ใบ้หวย)
   - `04 Trends` (กระแสเลขดัง)

## สิ่งที่อยู่ในไฟล์

โครงสร้างหน้า Sidebar, Header, Hero, การ์ดต่าง ๆ ถูกสร้างใหม่ให้ตรงกับเว็บ lekdee.kan.bio ทั้ง 4 หน้าหลัก (สี ระยะห่าง ตำแหน่ง ใกล้เคียงของจริง) เพื่อให้ต่อยอดออกแบบเพิ่มได้ทันที — ไม่ใช่ภาพสกรีนช็อต

**ข้อจำกัด:** ภาพประกอบ (นางฟ้า/ตัวการ์ตูนตอนเปิดหน้า Overview) ยังไม่ได้ใส่ เพราะเป็นภาพ AI-generated ที่ต้องอัปโหลดเป็นรูปจริง — ปัจจุบันแทนที่ด้วยพื้นที่ว่าง/องค์ประกอบตกแต่งแบบเรียบง่าย คุณสามารถลากรูปจริงจากเว็บมาวางทับเพิ่มเองได้ในภายหลัง

## โทนสี (คัดลอกไปตั้งเป็น Color Styles ใน Figma ได้เลย)

| ชื่อ | HEX | ใช้กับ |
|---|---|---|
| Background | `#0A0F0C` | พื้นหลังหน้าเว็บ |
| Sidebar BG | `#0D1310` | พื้นหลัง sidebar |
| Card BG | `#121A15` | การ์ดทั่วไป |
| Card Border | `#212B24` | เส้นขอบการ์ด |
| Text Primary | `#F4F7F2` | หัวข้อ/ข้อความหลัก |
| Text Secondary | `#9AA69E` | ข้อความรอง |
| Text Muted | `#5C6660` | แคปชัน/disclaimer |
| Accent (เขียวมะนาว) | `#B7F569` | ปุ่ม CTA, ไฮไลต์, badge จุดเขียว |

## ฟอนต์

เว็บต้นฉบับใช้ฟอนต์ไทยแบบกลม/โมเดิร์น — แนะนำใช้ **Prompt** หรือ **IBM Plex Sans Thai** ใน Figma (ทั้งคู่ติดตั้งฟรีผ่าน Google Fonts ในเมนู Figma) หัวข้อใหญ่ตั้ง Weight 700, ปุ่ม/label ตั้ง 600, เนื้อหาทั่วไป 400
